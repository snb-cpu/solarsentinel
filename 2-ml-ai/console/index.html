How a verdict is made

  1. Read the panel: voltage, current, four corner light sensors, eight temperatures and the tank level.
  2. Turn that into features: the heat pattern against the panel's median, how unevenly the light falls, and power against light.
  3. Classify the panel as healthy, dusty, shaded, hot cell or cracked cell. A second model judges it again after a wash, which separates dirt from a real fault.
  4. Apply the rules: a shadow is never washed, no wash if rain is forecast, refill a low tank first, and wash only when the loss per day is more than the cost of a wash.
  5. Send the verdict to the API in one request. The panel's node does the washing.

About the accuracy. The classifier was trained and tested on data from the physics simulator in this project (about 99.8% on that data). It has not been measured on real panels yet, and real data will be used to retrain it.
